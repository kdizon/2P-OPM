# 2P-OPM movies
This folder contains videos associated with the manuscript.

## Description
1. Bright-field movie of Drosophila embryogenesis: `WF-embryo_movie.mp4`
2. Volumetric comparison of 2P- and 1P-OPM imaging of gastruloids: `oids_movie.mp4`
3. Volumetric time-lapse of transcriptional dynamics during early fly development: `4D-transcription_movie.mp4`
4. Single-molecule movie of transcripts diffusing in a live fly embryo: `SM_movie.mp4`
